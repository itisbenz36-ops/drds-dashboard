# DRDS Dashboard – สคร.10 อุบลราชธานี

รายงานสถานการณ์การลงทะเบียนและการบันทึกผลงานวิจัย ในระบบบันทึกข้อมูลนักวิจัย กรมควบคุมโรค (DDC Researcher Data System – DRDS)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้า dashboard |
| `drds.xlsx` | ไฟล์ข้อมูล (1 sheet ต่อ 1 กลุ่มงาน) — หน้าเว็บอ่านจากไฟล์นี้ทุกครั้งที่เปิด |

## วิธีอัปเดตข้อมูล

1. แก้ไขข้อมูลในไฟล์ Excel ตามปกติ แล้ว **บันทึกชื่อไฟล์เป็น `drds.xlsx`**
2. เข้า repo บน GitHub → **Add file → Upload files** → ลากไฟล์ `drds.xlsx` มาวาง (ไฟล์เดิมจะถูกแทนที่)
3. กด **Commit changes**
4. รอ 1–2 นาที แล้วรีเฟรชหน้า dashboard

## รูปแบบไฟล์ Excel ที่ต้องคงไว้

- 1 sheet ต่อ 1 กลุ่มงาน (sheet "สรุป" ระบบจะข้ามให้เอง)
- แถวแรกเป็นหัวตาราง: `ลำดับที่ | ชื่อ - สกุล | ตำแหน่ง | ระดับ | ลงทะเบียน | บันทึกผลงาน`
- นับเฉพาะแถวที่มีเลขลำดับ
- ช่องลงทะเบียน / บันทึกผลงาน ถ้ามีคำว่า "ยังไม่" หรือว่าง จะนับเป็นยังไม่ทำ
- ชื่อ sheet ใหม่ที่ไม่รู้จักจะแสดงเป็นชื่อกลุ่มงานตามชื่อ sheet

## หมายเหตุ

ถ้าอ่าน `drds.xlsx` ไม่ได้ หน้าเว็บจะแสดงข้อมูลชุดสำรองที่ฝังอยู่ใน `index.html` (ข้อมูล ณ 2 พ.ย. 2569) พร้อมข้อความแจ้งที่ท้ายหน้า
